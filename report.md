# Final report: eng-c, continuation run (graphics-engine posts 05 and 06)

Both posts are finished, checked and committed on `api/eng-c` in five commits after the WIP commit. All figure scripts and code snippets have now been run. Both posts pass the page check in en, zh-cn and ja-jp at 390 and 1100 px: no broken images, no unrendered math, no console errors after the widget drags. The only exception is a 1 px overflow on post 05 at 390 px, caused by one display equation.

## Post 05: "Physics and simulation engines: from game physics to robot simulators"

- **Size:** about 6,900 English words, counting prose, captions and tables but not code. That is above the usual range, because the post covers six topics.
- **Figures:** 9, all generated by `graphics_engine_05.py`.
- **Widgets:** 2.
  - `graphics-engine-gjk` (from the earlier run).
  - `graphics-engine-stack` (**new**): a live box stack. You pick the solver (PGS, warm start, substeps, XPBD) and set the number of boxes, the mass ratio and the sweeps per frame; dragging down on the stack pushes the top box. Its solver gives exactly the same numbers as the figure script.
- **Papers cited:** 16.
- **Verified:**
  - Every figure script runs. I looked at each SVG and fixed four problems:
    - text overflowing the pipeline boxes;
    - zero values in the stack chart drawn as tiny bars (now marked "0");
    - wasted space in the chain plot;
    - unclear axis floors.
  - Captions now state what the scripts actually measured:
    - plain PGS leaves 10, 22 and 142 mm of penetration;
    - warm starting and substepping both reach 0;
    - XPBD leaves 0.25 to 2.6 mm;
    - the maximal-coordinate chain's error is 31%, 7.8% and 0.87% for 1, 4 and 32 iterations.
  - All 5 code blocks run. Their actual output is now shown as comments in all three languages.
  - Every engine and simulator version was re-checked against GitHub releases: Jolt 5.6.0, Box2D 3.2.0, Rapier 0.36.1, Isaac Sim 6.2.0, Isaac Lab 3.0.0, MuJoCo and MuJoCo Warp 3.17.0, Newton 1.7.0, Genesis 1.4.x, ManiSkill 3.0.1, habitat-sim 0.3.3, CARLA 0.9.16 / 0.10.0, ML-Agents Release 23.
  - PhysX is now pinned to **5.9.1 (27 Oct 2026)**.
- **Open issues:**
  - The new widget shows a simplification of the toy model: a contact stays active after a small gap opens, so a warm-started stack can rest 1–3 cm *above* its rest height. The widget caption explains this and names speculative contacts as the real-engine fix. The Python figures measure penetration only, so they are unaffected.
  - EPA (van den Bergen, GDC 2001) still has no verified link and is cited without one.

## Environment note

`site-build` fails inside the sandbox. The sandbox puts placeholder files into the repo, such as a device node called `scripts` and empty dotfiles like `.bashrc`, and Jekyll crashes on `scripts` (Errno::EACCES). Retrying outside the sandbox gave the same error.

To build, I copied the site to `/tmp/sitecopy` without those files and ran `site-build` and `site-check` there with `SITE_DIR` pointing to the copy. Nothing in the repository was changed for this. The placeholder files show up as untracked and I left them uncommitted.
