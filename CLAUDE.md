# CLAUDE.md

Personal academic website of Zehua Yang (PhD student, Yoshie Lab, Graduate School of IPS, Waseda
University). Trilingual (en-us default, zh-cn, ja-jp) Jekyll site based on multi-language-al-folio,
deployed to https://amadeusyzh.github.io/Takuyy/ by GitHub Actions on every push to `main`
(`.github/workflows/deploy.yml` builds into the `gh-pages` branch).

## Build and preview

```bash
bundle config set --local path vendor/bundle && bundle install
printf 'imagemagick:\n  enabled: false\n' > /tmp/local.yml   # imagemagick is only needed in CI
LANG=C.UTF-8 bundle exec jekyll build --config _config.yml,/tmp/local.yml   # or: jekyll serve
```

`baseurl` is `/Takuyy`, so a local static server must serve `_site` under `/Takuyy/`.

## Where things are

- Pages: `_pages/<lang>/` (about = home page with the Interactive Lab, publications, blog, cv).
- UI strings: `_data/<lang>/strings.yml` (also author names, lab demo texts, series names, categories).
- CV: `_data/<lang>/cv.yml`; PDFs are generated by `node bin/build_cv.js` into `assets/pdf/<lang>/cv.pdf`.
- Publications: `_bibliography/papers.bib` (shared by all languages).
- Interactive Lab (home page): `_includes/lab.liquid` + `assets/js/lab*.js` (hand-written WebGL 2:
  path tracer, ReSTIR, Gaussian World, XPBD cloth, foveated rendering).
- Blog: `_posts/<lang>/`, four series (graphics, neural-rendering, world-models, embodied-ai) plus a
  roadmap hub. Writing rules, including visualization rules, are in `docs/BLOG_GUIDE.md`; read
  it before adding or editing posts. Reading lists: `docs/reading-lists/`.
- Blog figures: Python scripts in `bin/figures/<series>/` (shared style `bin/figures/style.py`)
  write SVGs to `assets/img/blog/<series>/`; interactive widgets are `assets/js/widgets/*.js`.

## Conventions

- Every user-facing text exists in all three languages; the same file name across language folders.
- JavaScript in `assets/js/` stays ASCII-only (use \u escapes); no external JS libraries in demos.
- Do not invent facts about the owner (education, awards, contact details) or paper metadata;
  unverified items are marked with `TODO`.
- Commit author: `yangzehua <yangzehua@akane.waseda.jp>`.
