3. 光传输与渲染

前面章节中的路径追踪器和 ReSTIR都是蒙特卡洛估计器。几乎所有渲染研究都围绕两件事之一：降低这些估计器的方差，或者用一个计算代价更低的、学习得到或拟合得到的模型来替换计算的一部分。2026 年在这两方面都有出色的例子。

讲透一个概念：控制变量

直观理解。 如果你必须估计 $I = \int f$，并且你知道一个与 $f$ 相似的函数 $g$，其积分 $G = \int g$ 你恰好知道，那么只需用蒙特卡洛去估计差 $f - g$，再把 $G$ 加回来。这个差既小又平滑，所以它的估计噪声要小得多。

公式。 设 $N$ 个样本 $X_i$ 从定义域（这里是 $[0,1]$）上均匀抽取，系数为 $\beta$ 的控制变量（control variates）估计器为

\[\hat I_{\text{CV}} = \frac{1}{N}\sum_{i=1}^{N}\bigl[f(X_i) - \beta\, g(X_i)\bigr] + \beta\,G .\]

对任意 $\beta$ 它都是无偏的，因为 $\mathbb E[g(X)] = G$。它的方差为

\[\operatorname{Var}[\hat I_{\text{CV}}] = \frac{1}{N}\left(\sigma_f^2 - 2\beta\,\operatorname{Cov}(f,g) + \beta^2\sigma_g^2\right),\]

这是关于 $\beta$ 的抛物线。令导数为零得到 $\beta^* = \operatorname{Cov}(f,g)/\sigma_g^2$，代回后得到 $\operatorname{Var} = \sigma_f^2(1-\rho^2)/N$，其中 $\rho$ 是 $f(X)$ 与 $g(X)$ 之间的相关系数。$g$ 越贴近 $f$，$\rho^2$ 就越接近 1，被消除的方差也就越多。

算例。 取 $[0,1]$ 上的 $f(x) = e^x$（$I = e-1 \approx 1.71828$）和 $g(x) = 1 + x$（$G = 1.5$）。于是 $\sigma_f^2 = \frac{e^2-1}{2} - (e-1)^2 \approx 0.24204$，$\sigma_g^2 = 1/12$，$\operatorname{Cov}(f,g) = \mathbb E[xe^x] - \tfrac12(e-1)$，即 $1 - 0.85914 = 0.14086$。因此 $\beta^* \approx 1.690$，$\rho^2 \approx 0.9837$。取 $N = 8$ 个样本时，普通估计器的标准差为 $\sqrt{0.24204/8} \approx 0.174$，而控制变量估计器为 $\sqrt{0.24204 \cdot 0.0163/8} \approx 0.022$：在样本数相同的情况下，方差降低约 60 倍。

用模拟得到同样的数字，并像渲染器那样从样本中拟合 $\beta$：

import numpy as np

rng = np.random.default_rng(0)
f = np.exp                      # integrand on [0, 1]
g = lambda x: 1 + x             # control variate with known integral G
I, G = np.e - 1, 1.5

x = rng.random(1_000_000)       # pilot samples to fit beta
beta = np.cov(f(x), g(x))[0, 1] / np.var(g(x), ddof=1)

X = rng.random((100_000, 8))    # 100k independent estimates, N = 8 samples each
mc = f(X).mean(axis=1)
cv = (f(X) - beta * (g(X) - G)).mean(axis=1)
print(round(beta, 3), round(mc.std(), 3), round(cv.std(), 4))   # about 1.69 0.174 0.022
print(round(mc.mean(), 3), round(cv.mean(), 3), round(I, 3))     # 1.718 1.718 1.718: both unbiased

在渲染中，$g$ 绝不会是一个玩具多项式。它可以是相邻像素或上一帧中看到的颜色（下面的 ReSTCV），可以是一个拟合出来的光照模型，也可以是神经网络的预测（神经控制变量这一系列工作）。估计器本身和它之所以有效的原因，与上面完全一样。

论文

A Generalizable Light Transport 3D Embedding for Global Illumination：Bing Xu 等，SIGGRAPH 2026 Conference Papers，已发表，2026 年 7 月。大多数用于全局光照（global illumination, GI）的学习型捷径仍然需要路径追踪器或光栅化的光照缓冲作为输入。这里用一个 Transformer 把场景本身（一个携带几何与材质的点云）编码成 3D 嵌入。渲染时，通过交叉注意力汇集附近的嵌入点，来预测查询点处的光照。这个嵌入的目标是能够跨场景泛化，并可适配到其他渲染任务。它建立在第 4 章的渲染方程和第 5 章的 GI 问题之上。

Gaussian Light Transport（项目主页）：Patrick Attimont 等，SIGGRAPH Asia 2026 (Conference Track)，已接收，2026 年 12 月。GI 中与视角无关的部分被表示为位置、方向、法线和材质上的高斯混合。其参数通过让混合满足渲染方程来拟合，也就是最小化混合与传输算子作用一次之后的结果之间的残差，思路类似 Neural Radiosity。一个剔除步骤使拟合保持在可处理的规模，而对混合的求值足够快，可以实时显示。这篇论文有意思之处在于：3D 高斯泼溅中大家熟悉的高斯基元，在这里被用来求解光传输本身，而不是拟合照片。建立在第 4 章之上。

Spatio-Temporal Control Variates with ReSTIR for Real-Time Rendering（项目主页）：Zhong Shi 等，SIGGRAPH 2026 Conference Papers，已发表，2026 年 7 月。ReSTIR 每个像素只保留一个样本，由亮度这样的标量目标函数来选择，因此在场景中存在不同颜色的光源、采样数又很低时，会出现颜色噪声。这篇论文加入了控制变量，用的正是上面推导过的估计器：从相邻像素和之前帧累积的颜色估计充当 $g$，储备池（reservoir）中的样本只估计两者之差。作者报告以较小的代价获得了更低、更稳定的颜色方差。它是第 6 章中 RIS 与储备池机制的直接扩展。

ToF ReSTIR: Time-of-Flight Rendering with Spatio-temporal Reservoir Resampling：Juhyeon Kim 等，SIGGRAPH 2026 (ACM TOG 45(4))，已发表，2026 年 7 月。飞行时间（time-of-flight）传感器（激光雷达、门控相机）记录的不只是有多少光，还有光何时到达。当 ReSTIR 重用相邻像素的路径时，被重用的路径通常光程不同，这就破坏了时间约束。这篇论文设计了一种尊重路径长度的偏移映射（shift mapping），使时空重用能够以交互速率用于瞬态渲染和时间门控渲染。它表明第 6 章中“偏移映射 + 雅可比”的视角已经变得多么灵活，并且对模拟机器人和汽车的传感器很重要。

Neural Caching of Prefiltered Radiance for Specular Lighting：Dmitrii Klepikov 等，arXiv 预印本，2026 年 10 月。神经辐射缓存（一个在线训练、用来存储间接光的网络，见第 6 章）能很好地处理漫反射光，但对尖锐的镜面波瓣则力不从心。这篇预印本用反射方向来索引缓存，并在按粗糙度预滤波的辐射度上训练它。然后通过第 4 章中基于图像的光照里大家熟悉的 split-sum 近似，把缓存与预计算的 BRDF 表结合起来。作者报告在他们的测试场景上，镜面质量优于标准缓存。

Beyond Positional Encoding: A 5D Spatio-Directional Hash Encoding：Philippe Weier 等，arXiv 预印本，2026 年 3 月。多分辨率哈希网格是快速辐射场背后的编码（神经渲染 3），它对位置效果很好，但对球面上的方向效果不佳。这篇论文为方向构建了一个分层的测地线网格，并把它与空间哈希网格结合成一个 5D 编码。它的主要应用是神经路径引导（path guiding）：学习光从哪里来，使第 5 章中的路径追踪器更频繁地采样重要方向。作者报告在相同采样数下方差更低。

发展方向。 有三个方向很突出。第一，ReSTIR 家族不断吸收经典的蒙特卡洛工具：控制变量、路径引导和新的偏移映射。第二，“渲染器内部的神经方法”正在变得具体：针对某一个子问题量身定制的缓存、编码和嵌入，取代了通用的 MLP。第三，高斯基元正从场景表示扩展到光传输本身。光谱传输与体积传输见体积章节，实时 GI 系统见第 11 章。

4. 神经与混合表示

3D 高斯泼溅（3D Gaussian Splatting, 3DGS）让数以百万计的柔软、依赖视角的椭球成为标准的场景表示。2026 年的论文对它们提出了图形学的问题：我们能对它们做光线追踪吗？能不能去掉排序？什么基元适合毛发？与此同时，神经网络正在进入实时引擎的材质与纹理管线。

讲透一个概念：光线与 3D 高斯相遇的位置

光栅化 3DGS 时，每个高斯被投影成一个 2D 椭圆（神经渲染 4）。光线追踪则是沿光线对每个高斯求值，这样可以处理畸变相机、反射和次级光线。每个高斯光线追踪器都必须回答的问题是：沿光线的哪个位置，这个高斯的贡献最大，贡献有多大？

公式。 均值为 $\boldsymbol\mu$、协方差为 $\Sigma$ 的高斯，其密度为 $G(\mathbf x) = \exp\left(-\tfrac12 q(\mathbf x)\right)$，其中 $q(\mathbf x) = (\mathbf x-\boldsymbol\mu)^\top\Sigma^{-1}(\mathbf x-\boldsymbol\mu)$ 是马氏距离（Mahalanobis distance）的平方。在光线 $\mathbf x(t) = \mathbf o + t\mathbf d$ 上，$q$ 是关于 $t$ 的二次函数：

\[q(t) = (\mathbf o + t\mathbf d - \boldsymbol\mu)^\top \Sigma^{-1} (\mathbf o + t\mathbf d - \boldsymbol\mu), \qquad \frac{dq}{dt} = 2\,\mathbf d^\top\Sigma^{-1}(\mathbf o + t\mathbf d - \boldsymbol\mu).\]

令导数为零，得到峰值位置

\[t^* = \frac{\mathbf d^\top\Sigma^{-1}(\boldsymbol\mu - \mathbf o)}{\mathbf d^\top\Sigma^{-1}\mathbf d}, \qquad G_{\max} = \exp\!\left(-\tfrac12\, q(t^*)\right).\]

$t^{\ast}$ 不是光线上按普通距离离 $\boldsymbol\mu$ 最近的点。它是在高斯自身度量下最近的点，这个度量会沿短轴方向拉伸空间。

算例。 令 $\boldsymbol\mu = \mathbf 0$，$\Sigma = \operatorname{diag}(4,1,1)$（标准差为 2、1、1），$\mathbf o = (-4,-1,0)$，$\mathbf d = (1,1,0)/\sqrt2$。于是 $\Sigma^{-1} = \operatorname{diag}(0.25,1,1)$，$\mathbf d^\top\Sigma^{-1}(\boldsymbol\mu-\mathbf o) = (0.25\cdot4 + 1)/\sqrt2 = 1.4142$，$\mathbf d^\top\Sigma^{-1}\mathbf d = 0.625$，所以 $t^{\ast} = 2.263$。该点为 $(-2.4, 0.6, 0)$，$q = 0.25\cdot5.76 + 0.36 = 1.8$，因此 $G_{\max} = e^{-0.9} = 0.407$。欧氏距离最近的点位于 $t = \mathbf d\cdot(\boldsymbol\mu-\mathbf o) = 3.536$，那里只有 $G = e^{-1.406} = 0.245$。

import numpy as np

Sigma = np.diag([4.0, 1.0, 1.0]); Si = np.linalg.inv(Sigma)
mu = np.zeros(3)
o = np.array([-4.0, -1.0, 0.0]); d = np.array([1.0, 1.0, 0.0]) / np.sqrt(2)

t_star = d @ Si @ (mu - o) / (d @ Si @ d)
x = o + t_star * d - mu
print(t_star, np.exp(-0.5 * x @ Si @ x))      # 2.2627..., 0.4066...

t_e = d @ (mu - o)                             # closest point in Euclidean distance
y = o + t_e * d - mu
print(t_e, np.exp(-0.5 * y @ Si @ y))          # 3.5355..., 0.2451...

在二维中亲手试一试同样的计算。控件的初始状态正是上面的数值例子（$\sigma_x = 2$，$\sigma_y = 1$，$\mathbf o = (-4,-1)$，方向 $(1,1)/\sqrt2$），因此读数显示 $t^{\ast} = 2.26$、$G = 0.407$，而欧氏最近点为 $t = 3.54$、$G = 0.245$。

紫色：峰值 $t^{\ast}$，光线在此与高斯的一条等值椭圆相切（紫色虚线）。灰色：普通距离意义下的最近点，光线在此与以均值为圆心的圆相切（灰色虚线）。下方的曲线是 $G$ 沿光线的变化。旋转或拉伸高斯，观察两点如何分开：一般情况下两点不同，只在特殊情形下重合，例如各向同性的高斯、光线平行于某条主轴，或光线穿过均值。

高斯光线追踪器会把每个高斯包在一个包围代理（例如一个被拉伸的二十面体）里，放入 BVH（第 5 章），收集光线上的命中，对每个命中求 $G_{\max}$ 和不透明度，并按深度顺序做 alpha 合成，与体渲染完全一样。下面这些论文讨论的是如何让它变快，以及它的替代方案。

论文

GRay: Ray Tracing 3D Gaussians Near the Speed of Splats：Yohan Poirier-Ginter 等，I3D 2026 (PACMCGIT 9(1))，已发表，2026 年 5 月。光线追踪的高斯支持光栅化无法实现的效果，例如广角相机和次级光线，但它们一直比泼溅慢得多。GRay 是一个更快的高斯光线追踪器。论文还论证了：当场景包含非常多的小高斯时（密集初始化就会产生这种情况），光线追踪的扩展性比光栅化更好。作者报告渲染和优化速度比早先的 3DGRT 快数倍。它把第 5 章的 BVH 内容与 3DGS结合在了一起。

6. 物理模拟

第 7 章搭建了 XPBD 布料求解器，并概览了刚体和流体。2026 年的研究围绕鲁棒性（永不失效的接触）、GPU 上的性能，以及穿过整个模拟的梯度。

讲透一个概念：IPC 接触屏障

增量势能接触（Incremental Potential Contact, IPC）保证物体永不互相穿透。做法是在时间步能量中加入一个屏障项：当两个基元（点-三角形或边-边）之间的距离 $d$ 趋于零时，它无界增长；超过激活距离 $\hat d$ 后则为零：

\[b(d) = \begin{cases} -(d-\hat d)^2 \ln\!\left(\dfrac{d}{\hat d}\right), & 0 < d < \hat d,\\[4pt] 0, & d \ge \hat d . \end{cases}\]

检查其性质：$b(\hat d) = 0$ 且 $b’(\hat d) = 0$，所以屏障是平滑启动的。当 $d \to 0$ 时，$-\ln(d/\hat d) \to \infty$，因此从有效状态出发的线搜索，其任何一步都无法越过 $d = 0$。排斥力为

\[-b'(d) = 2(d-\hat d)\ln\!\left(\frac{d}{\hat d}\right) + \frac{(d-\hat d)^2}{d}.\]

数值上，取 $\hat d = 1$：$b(0.5) = 0.25\ln 2 = 0.173$，$b(0.1) = 0.81\ln 10 = 1.865$，$b(0.01) = 0.9801\ln 100 = 4.513$。能量只是对数增长，而力则像 $\hat d^2/d$ 那样增长。

import numpy as np

def barrier(d, dhat):
    return np.where(d < dhat, -(d - dhat) ** 2 * np.log(d / dhat), 0.0)

print(barrier(np.array([0.01, 0.1, 0.5, 2.0]), 1.0))   # about [4.513 1.865 0.173 0.]

与 XPBD 对穿透约束做投影相比，屏障把接触变成了一个平滑（尽管刚性）的能量，牛顿法可以对它做最小化。代价是每一步都要做带有大量接触对的非线性求解，这就是为什么 2026 年有这么多工作围绕 GPU 求解器和代码生成。

8. 成像与显示

这一节对 AR 和 VR 很重要。头显是一个渲染系统，其输出由人的视觉系统来接收，所以显示光学和感知就成了渲染问题的一部分。全息近眼显示能够重现光的波前，因而可以呈现真实的对焦线索，它是 2026 年的一大主题。

讲透一个概念：用 Gerchberg-Saxton 求纯相位全息图

直观理解。 全息显示器使用空间光调制器（spatial light modulator, SLM），这是一块像素屏幕，能以可编程的相位 $\varphi$ 延迟相干激光，但不能改变其振幅。在最简单的（远场）设置中，观看者看到的图像是 SLM 出射场的傅里叶变换。所以我们需要一个相位图案，使其傅里叶变换具有规定的振幅 $A$，而像平面上的相位可以自由选择。

公式。 记 $\mathcal F$ 为二维傅里叶变换，我们希望 $\lvert\mathcal F\{e^{i\varphi}\}\rvert \approx A$。Gerchberg-Saxton 算法在两个平面之间交替，并在每个平面上强制满足该处已知的条件：

\[\varphi^{(k)} = \arg \mathcal F^{-1}\!\left\{A\,e^{i\psi^{(k-1)}}\right\}, \qquad \psi^{(k)} = \arg \mathcal F\!\left\{e^{i\varphi^{(k)}}\right\}.\]

第一步保留 SLM 处的相位并把振幅设为 1，因为 SLM 只能显示相位。第二步保留图像中的相位，并把振幅替换为目标。每一步都是向该平面上已知条件的投影。这就是 Gerchberg 和 Saxton（1972）的算法，是当今基于优化的全息图生成方法的鼻祖。

import numpy as np

def gerchberg_saxton(A, iters, seed=0):
    psi = np.random.default_rng(seed).uniform(0, 2 * np.pi, A.shape)   # image-plane phase
    for _ in range(iters):
        phi = np.angle(np.fft.ifft2(A * np.exp(1j * psi)))   # phase-only SLM pattern
        R = np.fft.fft2(np.exp(1j * phi))                    # what the viewer sees
        psi = np.angle(R)
    return phi, np.abs(R) ** 2
yy, xx = np.mgrid[0:128, 0:128] - 63.5                       # target: ring plus cross
r = np.hypot(xx, yy)
A = ((r > 30) & (r < 38)).astype(float)
A[(abs(xx) < 4) & (abs(yy) < 22)] = 1.0
A[(abs(yy) < 4) & (abs(xx) < 22)] = 1.0
for k in (1, 5, 60):
    amp = np.sqrt(gerchberg_saxton(A, k)[1])
    s = (amp * A).sum() / (amp ** 2).sum()                   # best brightness scale
    print(k, round(np.sqrt(((s * amp - A) ** 2).mean() / (A ** 2).mean()), 3))

真实系统还要加入近场传播（角谱法）、3D 内容和经过相机标定的光学，并且用基于损失的梯度下降取代 Gerchberg-Saxton。这就是为什么损失的选择（HoOPOE）和光传输模型的选择（HoloPathTracer）都是研究问题。

论文

HoloPathTracer: Fast and Accurate Wave Path Tracing for Holography：Wenbin Zhou 等，SIGGRAPH 2026 (ACM TOG 45(4))，已发表，2026 年 7 月。计算机生成全息图通常分两步制作：先渲染辐射度（图像或分层），再由它们传播波。这种拆分会丢失深度和视角连续性，并且对光泽或镜面类表面处理得很差。HoloPathTracer 用蒙特卡洛路径追踪同时求解渲染方程和波传播积分。它重用路径，以很低的代价生成多个时间复用的相位全息图。硬件实验结果展示了正确的离焦、依赖视角的外观和反射。它是把路径追踪搬到波动光学，面向的是 XR的显示器。

HoOPOE: A Holography-Optimized Perceptual ObjectivE function：Ethan Chen 等，SIGGRAPH Asia 2026，已接收，2026 年 12 月。真实 SLM 上的全息图会出现散斑，也就是上图中可见的颗粒状噪声，而普通的图像损失并不能反映人眼对它的可见程度。作者围绕人对时空频率和颜色的敏感度构建了一个损失，其参数针对全息做了调节。在一项针对 3D 场景全息图的用户研究中，参与者更喜欢用它优化出的结果，胜过次优的损失。任何基于梯度的全息图管线都可以采用它。它与感知驱动的渲染（perception-aware rendering）和 XR相联系。

Dichoptic Foveation：Henry Kam 等，SIGGRAPH 2026 Conference Papers，已发表，2026 年 7 月。注视点渲染（foveated rendering）在眼睛不敏感的周边区域降低质量，通常对双眼做同样的处理。这项工作在周边区域给每只眼睛展示不同的频率内容，模糊一个视图而锐化另一个，并在 VR 头显中测量大脑如何融合这两者。测量结果被转换为刚可察觉差异（just-objectionable-difference, JOD）尺度，并用一个感知模型来拟合，再应用到注视点 360 度视频上。它为本站实验室中的注视点渲染增加了双眼线索，并与 XR 渲染相关。

PAColorHolo: A Perceptually-Aware Color Management Framework for Holographic Displays：Chun Chen 等，ACM TOG 45(2)，已发表，2026 年 3 月。全息显示器混合红、绿、蓝三种激光，要再现看起来正确的颜色出人意料地困难。该框架结合了色彩空间变换、照明的自适应控制，以及在标定中使用的相机颜色响应神经模型。它在模拟、光学原型和用户研究中得到了验证。颜色管理是颜色管线在显示一端的环节，这条管线始于第 3 章的着色。

Hybrid Foveated Path Tracing with Peripheral Gaussians for Immersive Anatomy：Constantin Kleinbeck 等，IEEE VR 2026，已发表，2026 年 3 月。在 VR 中对体积医学数据做路径追踪，效果极好，但对头显来说太慢；而预计算的高斯泼溅很快，却必须提前准备。该系统只对注视区域做路径追踪，并在周边显示一个高斯近似，该近似可以被快速重建，并根据中央凹的渲染结果逐步细化。由深度引导的重投影掩盖了延迟。它以随注视点变化的方式，把实时路径追踪与 3DGS结合起来。

发展方向。 面向头显的渲染正在变得由感知驱动、并且关注光学：基于人类视觉建模的损失、双眼与随注视点变化的渲染，以及基于物理的波动光学。对从事 AR/VR 和 HCI 的研究者来说，这些论文是图形学与用户研究之间的桥梁。

9. 制造与设计

用于形状、模拟和优化的图形学方法，也可以用来设计实体物件：3D 打印零件、针织品、剪纸（kirigami）和服装。本节的每一项工作都是 SIGGRAPH 2026 的论文。

AtomSlicer: Constant-Thickness Field-Aligned Non-Planar Slicing and Continuous Toolpaths for FFF（项目主页）：Giovanni Cocco 等，SIGGRAPH 2026 (ACM TOG 45(4))，已发表，2026 年 7 月。熔丝（FFF）打印机通常打印平面层。多轴打印机可以沿着弯曲的层打印，这能提高强度和表面质量，但层必须保持近似恒定的厚度，喷嘴还必须避免碰撞。该方法根据零件上的方向场和走向场，构建非平面的层和刀具路径，这些路径在每一层内是连续的，并且在层与层之间尽可能连续。它还会报告某个设计何时无法被制造。建立在第 8 章中曲面上的场之上。

Surface Power Diagrams for Knit Singularity Placement（DOI 10.1145/3811401）：Rahul Mitra 等，SIGGRAPH 2026 (ACM TOG 45(4))，已发表，2026 年 7 月。机器编织一个 3D 形状需要一张“针织图”，其奇异点（行开始、结束或合并的地方）必须被仔细放置。这篇论文用修改过的测地热核，把幂图（power diagram，即加权 Voronoi 图）推广到曲面网格上。它通过 Lloyd 式迭代来放置奇异点，并加入顺序约束，使无螺旋的针织图更加可靠。制作出的样品展示了结果。建立在第 8 章的测地线和 Voronoi 思想之上。

IsoGami: Rigid-Deployable Kirigami Materials From Isohedral Tilings（DOI 10.1145/3799902.3811127）：Guo Han 等，SIGGRAPH 2026 Conference Papers，已发表，2026 年 7 月。剪纸是把一张薄片切开，使其能够展开成新的形状。刚性可展开（rigid-deployable）的设计通过单一的运动打开，而不弯曲任何一块瓦片。该方法系统地搜索平面的等面铺砌（isohedral tiling），改变关节拓扑和瓦片形状。连杆分析只保留恰好有一个自由度的设计，然后对它们的展开做模拟。论文附带一个交互式浏览器和 3D 打印的原型。它与第 7 章中力学的约束视角相关。

Shellular Metamaterial Design via Compact Electric Potential Parametrization：Tianyi Huang 等，SIGGRAPH 2026 Conference Papers，已发表，2026 年 7 月。壳体超材料（shell-based metamaterials）是周期性的薄壁结构，在低密度下很强，但难以设计，评估代价也高。这里一个设计由几十个电荷来描述，壳体几何则由它们产生的电势推导得出。一条 GPU 均匀化（homogenization）管线可以快速计算等效弹性性质。两者结合，使交互式设计和面向目标刚度的逆向设计成为可能，并通过打印的原型得到验证。它用到了隐式曲面（第 8 章）和弹性（第 7 章）。

Learning Sewing Patterns via Latent Flow Matching of Implicit Fields：Cong Cao 等，SIGGRAPH 2026 Conference Papers，已发表，2026 年 7 月。一件衣服由缝合在一起的平面裁片制成，裁片的数量、形状和缝线差别很大，使得纸样很难生成。每个裁片被编码为其边界的符号距离场和其缝合端点的无符号距离场，位于带可微网格化的潜空间中。一个流匹配模型生成裁片集合，另一个独立的模块预测缝合方式。应用包括从图像估计纸样、补全和重新适配。它把第 8 章的隐式场与流匹配结合在一起。

发展方向。 计算设计不断从“模拟一个给定的设计”走向“搜索或生成设计空间”：铺砌、电荷配置、纸样的潜空间。GPU 上的快速评估（均匀化、模拟）使这一切成为交互式的。

10. 生成式 3D/4D 内容

生成式 3D 模型已在3D 与 4D 世界生成中从世界模型的角度讲过。图形学会议贡献的是生产所需要的东西：拓扑良好的原生网格、可控的高斯、尊重房间结构的布局，以及可以被模拟和做动画的资产。

Nexus: Native Mesh Generation with Diffusion：Hanxiao Wang 等，SIGGRAPH 2026 (ACM TOG 45(4))，已发表，2026 年 7 月。大多数网格生成器要么以自回归的方式把三角形作为 token 逐个输出，要么先生成一个场再从中提取网格。两者在拓扑上都有困难。Nexus 直接对顶点做扩散，表示为由粗到细的稀疏八叉树体素。第二个扩散模型生成逐顶点的嵌入，连接关系从中解码出来。作者报告结果优于自回归和两阶段基线，并且在一项盲测研究中得到 3D 从业者的偏好。建立在网格（第 8 章）之上。

Generative 3D Gaussians with Learned Density Control：Runjie Yan 等，SIGGRAPH 2026 Conference Papers，已发表，2026 年 7 月。生成式高斯模型通常把基元放在固定网格或固定大小的数组上，这会把预算浪费在空旷或简单的区域。这里高斯的中心是从八叉树上的一个可学习密度中采样的，用渲染监督进行训练，再由一个潜在扩散模型根据一张图像生成这种表示。一种基于 Sobol 序列的 token 锚定方案加速了扩散训练。基元的数量可以在生成时选择。它把 3DGS的稠密化问题与扩散结合了起来。

CasLayout: Cascaded 3D Layout Diffusion for Indoor Scene Synthesis with Implicit Relation Modeling：Yingrui Wu 等，SIGGRAPH 2026 (ACM TOG 45(4))，已发表，2026 年 7 月。生成出来的房间必须尊重墙、门和窗，以及家具之间合理的关系，而所有物体之间的稠密关系图会带来噪声。该方法运行四个条件扩散阶段：物体数量与类别、尺寸、潜在关系，最后是有向包围盒，并把建筑结构作为约束。稀疏的关系图提供了控制。它还借助语言模型和视觉语言模型，支持零样本的图像到场景生成。与3D 世界生成相关。

SIMART: Decomposing Monolithic Meshes into Sim-ready Articulated Assets via MLLM（项目主页）：Chuanrui Zhang 等，SIGGRAPH 2026 Conference Papers，已发表，2026 年 7 月。机器人模拟器需要铰接物体（带门的柜子、可滑动的抽屉），而扫描得到或生成的网格是整块的。SIMART 用一个多模态大语言模型把网格拆分为部件，同时预测它们的关节，避免了跨阶段的误差累积。一个稀疏的 3D VQ-VAE 让 token 的数量保持在可控范围内。论文在机器人模拟中演示了这些资产。这是面向具身智能模拟器和引擎的资产生成。

R-DMesh: Video-Guided 3D Animation via Rectified Dynamic Mesh Flow（项目主页）：Zijie Wu 等，SIGGRAPH 2026 Conference Papers，已发表，2026 年 7 月。让用户的静态网格跟随参考视频做动画，当网格的初始姿态与视频不同时就会失效。一个 VAE 把输入拆分为基础网格、相对运动，以及一个学习得到的、用来对齐起始姿态的校正（rectification）偏移。然后由一个以视频为条件的整流流（rectified-flow）扩散 Transformer 生成网格动画。作者构建了一个包含 50 万多个模拟网格序列的数据集，它也支持重定向和 4D 生成。建立在第 9 章和 4D 生成之上。

GaussiAnimate: Rig Animatable Categories with Level of Dynamics：Jiaxin Wang 等，SIGGRAPH Asia 2026，已接收，2026 年 12 月。动态的 4D 采集结果以高斯或网格序列存储，很难用新的姿态重新做动画。该方法把一个序列压缩为带蒙皮权重的自由形态骨骼，并从规范形状中提取基于曲率的骨架。然后一个无需学习的、逐部件的运动匹配步骤检索并混合已有的运动，以合成新的运动。它不需要模板，并且能处理拓扑变化。它把第 9 章的蒙皮与运动匹配，同 3DGS 前沿中的动态高斯结合在了一起。

发展方向。 “生成一个漂亮的物体”正让位于“生成一个可用的资产”：拓扑良好的原生网格、预算可控的基元、带约束的房间，以及已铰接、已绑定骨骼、可以直接用于模拟的物体。图形学会议是以管线能用输出做什么来评判生成模型的。

11. 跨领域趋势

通读这八个小节，同样的几股力量一再出现。

  1. 神经基元无处不在，但以混合的形式。 高斯现在可以被光线追踪（GRay）、被点泼溅（Gaussian Point Splatting）、被用作光传输的基（Gaussian Light Transport），也被附着在虚拟形象网格上。网络以对经典模型的修正形式进入：GGX BRDF 加一个网络，块压缩纹理加一个解码器，ReSTIR 估计器加一个控制变量。经典结构使代价和行为保持可预测。
  2. 可微性是基础设施。 Iskra（几何求解器）、考虑局部性的自动微分（网格能量）、DiffSurFlow（流体）、用伴随法拟合的皱褶模型，以及线基元光栅化器，都把梯度看作系统所提供的东西，而不是每篇论文各自重新推导的东西。这就是第 12 章的纲领被带入模拟和几何。
  3. 着色器和求解器内部的机器学习。 神经缓存、由超网络解码的纹理和混合 BRDF，被设计成能在现代 GPU 的张量硬件上逐像素实时运行。引擎系列会跟进这些组件如何落地到生产引擎中。
  4. 生成式先验遇上物理约束。 扩散和流匹配现在可以生成四边形布局、缝纫纸样、网格、房间和运动，而图形学所增加的价值就在约束之中：拓扑、物理有效性、缝线、运动学、可用于模拟。
  5. 模拟与渲染趋于融合，二者都在为具身智能提供养分。 ToF ReSTIR 模拟传感器，SIMART 制作可直接用于模拟的资产，InstantMimic 和 GPC 大规模训练基于物理的技能，而 GPU 接触求解器是机器人模拟器的核心。这是通向世界模型和具身智能的桥梁，也通向物理引擎。
  6. 感知成为渲染的一部分。 双眼注视点渲染（dichoptic foveation）、针对全息的感知损失和感知颜色管理，都把人的视觉系统视为管线的最后一级，这个主题对任何构建 AR/VR 系统的人都很重要。

12. 如何跟进图形学研究

这个领域发展很快，但信息来源是稳定的。一套实用的日常做法：

  • Ke-Sen Huang 的论文列表（kesen.realtimerendering.com）为每个主要会议收集论文标题，并在论文出现时附上作者主页、PDF、视频和代码的链接。截至本文写作时，有 SIGGRAPH、SIGGRAPH Asia（有条件接收的论文）、Eurographics 和 I3D 的 2026 年页面。这是最好的单一入口。
  • ACM TOG 与 ACM Digital Library（dl.acm.org/journal/tog）提供权威版本。SIGGRAPH 期刊类论文出现在每卷的第 4 期，SIGGRAPH Asia 的则在第 6 期；会议类论文出现在单独的论文集中。Crossref（api.crossref.org/works/<doi>）是核对某个 DOI 的会议、卷号和日期的一种快捷而开放的方式。
  • arXiv cs.GR（arxiv.org/list/cs.GR/recent）：留意“comments”字段。作者通常会在那里写上“Accepted to SIGGRAPH Asia 2026”，没有这样的说明就意味着预印本。相关工作也会出现在 cs.CV 和 cs.LG 中。
  • Eurographics Digital Library（diglib.eg.org）收录 CGF、EGSR、SCA、SGP 和 HPG 的论文。
  • Technical Papers Fast Forward 与视频。 每届 SIGGRAPH 和 SIGGRAPH Asia 都以一场 fast-forward 环节开场，每篇论文都有一段很短的推介，而且大多数论文都有补充视频。观看它们是浏览整个会议最快的方式。官方网站是 s2026.siggraph.org 和 asia.siggraph.org/2026。
  • 课程（Courses）。 SIGGRAPH 的课程（例如长期举办的 Physically Based Shading 和 Advances in Real-Time Rendering 系列，可从 blog.selfshadow.com 链接到）是为教学而写的，也是从本博客通向论文的最佳桥梁。
  • 开源代码。 许多论文在项目主页上链接了 GitHub 仓库。每个月把一篇论文的代码跑起来，比浏览十篇学到的更多。
  • 读书会。 每周挑一场 fast forward 的内容，一起读一篇论文，并尝试复现一张图。本章中的“讲透一个概念”框就是应当追求的深度的范例。

练习

  1. 控制变量。 在算例中，把 $g(x) = 1+x$ 替换为 $g(x) = 1 + x + x^2/2$（$e^x$ 的二阶泰勒多项式）。用解析方法或 NumPy 计算 $G$、$\beta^*$ 和方差的降低程度。

    提示

    $G = 1 + \tfrac12 + \tfrac16 = 5/3$，$\sigma_g^2 \approx 0.1889$，$\operatorname{Cov}(f,g) \approx 0.2136$（用到 $\mathbb E[x^2e^x] = e-2$），所以 $\beta^* \approx 1.131$，$\rho^2 \approx 0.9981$。残余方差比用 $1+x$ 时小约 9 倍，比普通蒙特卡洛小约 500 倍。

  2. 光线上的高斯。 证明 $q(t)$ 是关于 $t$ 的凸二次函数，并且 $q(t^{\ast}) = q(0) - \frac{(\mathbf d^\top\Sigma^{-1}(\boldsymbol\mu-\mathbf o))^2}{\mathbf d^\top\Sigma^{-1}\mathbf d}$。然后用代码片段做数值验证。

    提示

    把 $q(t)$ 写成 $q(t) = a t^2 - 2bt + c$，其中 $a = \mathbf d^\top\Sigma^{-1}\mathbf d > 0$，$b = \mathbf d^\top\Sigma^{-1}(\boldsymbol\mu-\mathbf o)$，$c = q(0)$，然后配方。

  3. IPC 屏障。 证明 $b$ 在 $d = \hat d$ 处二阶连续可微：计算 $d$ 从下方趋于 $\hat d$ 时的 $b’$ 和 $b’’$，并与从上方得到的值 $0$ 比较。为什么牛顿法在意这一点？

    提示

    令 $u = d - \hat d$，则 $b = -u^2\ln(1 + u/\hat d)$。展开对数：在 $u = 0$ 附近 $b \approx -u^3/\hat d$，所以 $b’$ 和 $b’’$ 从下方都趋于 0，屏障是 $C^2$ 的。牛顿法用到 Hessian，所以当一个接触对进入激活集时，如果 $b’’$ 发生跳变，迭代就会停滞或振荡。

  4. 全息。 在你选择的目标上，分别用 1、5、20 和 100 次迭代运行 Gerchberg-Saxton 代码片段，并画出误差。然后用恒定的初始相位代替随机相位。会发生什么？为什么随机相位有帮助？

    提示

    用恒定相位时，$\mathcal F^{-1}\{A\}$ 把大部分能量放进少数几个低频的 SLM 像素里。把振幅强制设为 1 会把这个频谱压平，这相当于一个很强的高通滤波器：主要只有目标的边缘得以保留，迭代往往会停滞。随机相位把能量均匀地分散到整个 SLM 上，所以纯相位约束丢失的信息更少，代价是出现散斑。
