为什么重要

在上一篇中，每个控制器都是根据模型手工设计的。 这对在自由空间中运动的机械臂行得通，但对在碎石上奔跑的四足机器人、或者转动方块的灵巧手就非常困难了，因为接触每秒要 通断数百次。强化学习（reinforcement learning, RL）用优化取代手工设计：写下一个奖励，让机器人在仿真器里尝试数百万次， 再把得到的策略迁移到硬件上。大约从 2019 年起，这套配方已成为构建运动控制器的标准方法，而它的思想（优势函数、熵、 域随机化）在本系列后面的模仿学习、VLA 微调和世界模型训练中还会反复出现。

  • 概率：期望、对数导数技巧、高斯分布。

1. RL 问题

马尔可夫决策过程

MDP 是一个元组 $(\mathcal{S}, \mathcal{A}, P, r, \gamma, \rho_0)$：状态、动作、转移动力学 \(P(s' \mid s, a)\)、奖励 $r(s, a)$、 折扣 $\gamma \in [0, 1)$ 和初始状态分布 $\rho_0$。一个（随机）策略 $\pi_\theta(a \mid s)$ 产生轨迹 $\tau = (s_0, a_0, s_1, a_1, \dots)$，目标是期望折扣回报

\[J(\theta) = \mathbb{E}_{\tau\sim\pi_\theta}\left[\sum_{t=0}^{\infty} \gamma^t r(s_t, a_t)\right].\]

真实机器人是部分可观测的（POMDP）：策略看到的是观测 $o_t$（关节编码器、IMU、图像），而不是完整状态（精确的接触力、 地面摩擦）。实践中用观测历史、循环网络，或第 4 节中的特权信息技巧来处理。

对机器人来说，建模选择和算法同样重要：

MDP 要素 腿式机器人的典型选择
观测 基座角速度、投影重力、关节位置与速度、上一步动作、速度指令、（高度图）
动作 给 200 Hz 到 1 kHz PD 回路的关节位置目标 $q^{\text{des}}$；策略运行在 50 Hz
奖励 跟踪指令速度，惩罚力矩、关节加速度、动作变化率、足部打滑、基座姿态
回合 20 s，摔倒（基座触地）时终止，随机化初始状态与地形

价值函数与贝尔曼方程

策略的状态价值与动作价值为

\[V^\pi(s) = \mathbb{E}_\pi\left[\sum_{k\ge 0}\gamma^k r_{t+k} \,\middle\vert\, s_t = s\right], \qquad Q^\pi(s,a) = \mathbb{E}_\pi\left[\sum_{k\ge 0}\gamma^k r_{t+k} \,\middle\vert\, s_t = s, a_t = a\right],\]

优势函数（advantage）$A^\pi(s,a) = Q^\pi(s,a) - V^\pi(s)$ 衡量动作 $a$ 比策略的平均水平好多少。它们满足贝尔曼期望方程

\[Q^\pi(s,a) = r(s,a) + \gamma\,\mathbb{E}_{s'\sim P,\,a'\sim\pi}\left[Q^\pi(s',a')\right],\]

而最优动作价值满足贝尔曼最优方程 \(Q^{\ast}(s,a) = r + \gamma\,\mathbb{E}_{s'}[\max_{a'} Q^{\ast}(s',a')]\)。Q 学习和 DQN（Mnih 等 2015） 迭代的是后者，但在连续高维动作空间上取 $\max$ 很别扭，所以机器人领域主要使用策略梯度（policy gradient）和 演员-评论家（actor-critic）方法。

2. 策略梯度

策略梯度定理

利用 $\nabla_\theta p_\theta(\tau) = p_\theta(\tau)\nabla_\theta\log p_\theta(\tau)$ 以及动力学不依赖于 $\theta$ 这一事实，可以得到 （Williams 1992；Sutton 等 2000）

\[\nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta}\left[\sum_t \nabla_\theta\log\pi_\theta(a_t\mid s_t)\, \hat A_t\right],\]

其中 $\hat A_t$ 可以是未来回报（REINFORCE）、回报减去基线 $b(s_t)$，或者优势估计。减去与状态相关的基线不会使梯度有偏， 却能大幅降低方差。直观地说，梯度会提高结果好于预期的动作的对数概率，降低其他动作的对数概率。

对连续控制，策略通常是对角高斯 $\pi_\theta(a\mid s) = \mathcal{N}(\mu_\theta(s), \mathrm{diag}(\sigma^2))$，其中 $\log\sigma$ 与状态无关、 由学习得到。

广义优势估计

有了学习的评论家 $V_\phi$，定义 TD 残差 $\delta_t = r_t + \gamma V_\phi(s_{t+1}) - V_\phi(s_t)$。GAE（Schulman 等 2016）用指数衰减 权重对 $k$ 步优势估计取平均：

\[\hat A_t^{\mathrm{GAE}(\gamma,\lambda)} = \sum_{l=0}^{\infty} (\gamma\lambda)^l\,\delta_{t+l}.\]

$\lambda = 0$ 得到低方差但有偏的一步 TD 优势；$\lambda = 1$ 得到无偏但高方差的蒙特卡洛优势。$\lambda \approx 0.95$ 是常用的折中。 评论家回归到目标 $\hat R_t = \hat A_t + V_\phi(s_t)$。

信赖域与 PPO

朴素的策略梯度很脆弱：一步走得太大就可能让策略崩溃，此后收集的数据也就毫无用处。TRPO（Schulman 等 2015）在新旧策略 之间 KL 散度约束下最大化一个替代目标。PPO（Schulman 等 2017）用一个一阶技巧获得了大部分好处。记概率比 $\rho_t(\theta) = \pi_\theta(a_t\mid s_t)/\pi_{\theta_{\text{old}}}(a_t\mid s_t)$，它最大化

\[L^{\text{CLIP}}(\theta) = \mathbb{E}_t\left[\min\left(\rho_t(\theta)\hat A_t,\; \operatorname{clip}(\rho_t(\theta), 1-\epsilon, 1+\epsilon)\,\hat A_t\right)\right],\]

通常取 $\epsilon = 0.2$。$\min$ 使它成为一个悲观的下界：一旦概率比朝着改进目标的方向离开 $[1-\epsilon, 1+\epsilon]$，梯度就消失， 于是没有继续移动的动力。这让 PPO 可以把每批数据重复用于多轮小批量 SGD。完整损失再加上价值损失和可选的熵奖励：

\[L(\theta,\phi) = -L^{\text{CLIP}}(\theta) + c_v\,\mathbb{E}_t\left[(V_\phi(s_t) - \hat R_t)^2\right] - c_e\,\mathbb{E}_t\left[\mathcal{H}(\pi_\theta(\cdot\mid s_t))\right].\]

PPO 是同策略（on-policy）的，样本效率低，但它简单、稳定、极易并行。当一块 GPU 上有成千上万个仿真机器人时，样本效率远不如 墙钟时间重要，这就是 PPO 成为 Isaac Lab、legged_gym 以及大多数运动控制论文默认算法的原因。

紧凑的 PyTorch PPO

下面的文件是自包含的：一个演员-评论家网络、GAE、PPO 更新，以及一个向量化的玩具任务，其中 64 个质点必须移动到原点 （相当于一个到达任务的替身）。在笔记本 CPU 上几分钟就能跑完。

import torch
import torch.nn as nn

class ActorCritic(nn.Module):
    def __init__(self, obs_dim, act_dim, hidden=64):
        super().__init__()
        self.pi = nn.Sequential(nn.Linear(obs_dim, hidden), nn.Tanh(),
                                nn.Linear(hidden, hidden), nn.Tanh(), nn.Linear(hidden, act_dim))
        self.v = nn.Sequential(nn.Linear(obs_dim, hidden), nn.Tanh(),
                               nn.Linear(hidden, hidden), nn.Tanh(), nn.Linear(hidden, 1))
        self.log_std = nn.Parameter(torch.full((act_dim,), -0.5))

    def dist(self, obs):
        return torch.distributions.Normal(self.pi(obs), self.log_std.exp())

def gae(rew, val, done, last_val, gamma=0.99, lam=0.95):
    """rew, val, done: [T, N] tensors (N parallel envs). Returns advantages and returns."""
    T = rew.shape[0]
    adv = torch.zeros_like(rew)
    next_val, running = last_val, torch.zeros_like(last_val)
    for t in reversed(range(T)):
        mask = 1.0 - done[t]
        delta = rew[t] + gamma * next_val * mask - val[t]
        running = delta + gamma * lam * mask * running
        adv[t] = running
        next_val = val[t]
    return adv, adv + val

def ppo_update(model, opt, obs, act, logp_old, adv, ret,
               clip=0.2, vf_coef=0.5, ent_coef=0.0, epochs=10, minibatch=256):
    """One PPO update on a flattened batch of B transitions."""
    adv = (adv - adv.mean()) / (adv.std() + 1e-8)
    B = obs.shape[0]
    for _ in range(epochs):
        for idx in torch.randperm(B).split(minibatch):
            d = model.dist(obs[idx])
            logp = d.log_prob(act[idx]).sum(-1)
            ratio = (logp - logp_old[idx]).exp()
            surr = torch.min(ratio * adv[idx],
                             ratio.clamp(1 - clip, 1 + clip) * adv[idx])
            v_loss = (model.v(obs[idx]).squeeze(-1) - ret[idx]).pow(2).mean()
            loss = -surr.mean() + vf_coef * v_loss - ent_coef * d.entropy().sum(-1).mean()
            opt.zero_grad()
            loss.backward()
            nn.utils.clip_grad_norm_(model.parameters(), 0.5)
            opt.step()

# --- a toy "reaching" task: a 2-D point mass must move to the origin ---
class PointReach:
    def __init__(self, n, horizon=50):
        self.n, self.H = n, horizon
        self.damp, self.gain = 0.9, 0.1               # nominal physics
    def reset(self):
        self.pos = torch.rand(self.n, 2) * 2 - 1
        self.vel = torch.zeros(self.n, 2)
        self.t = torch.zeros(self.n)
        return torch.cat([self.pos, self.vel], -1)
    def step(self, a):
        a = a.clamp(-1, 1)
        self.vel = self.damp * self.vel + self.gain * a  # simple damped dynamics
        self.pos = self.pos + 0.1 * self.vel
        self.t += 1
        rew = -self.pos.norm(dim=-1) - 0.01 * a.pow(2).sum(-1)
        done = (self.t >= self.H).float()
        if done.any():                                # auto-reset finished envs
            k = done.bool()
            self.pos[k] = torch.rand(int(k.sum()), 2) * 2 - 1
            self.vel[k] = 0.0
            self.t[k] = 0
        return torch.cat([self.pos, self.vel], -1), rew, done

torch.manual_seed(0)
env, T = PointReach(n=64), 128
model = ActorCritic(4, 2)
opt = torch.optim.Adam(model.parameters(), lr=3e-4)
obs = env.reset()
for it in range(150):
    buf = {k: [] for k in ["obs", "act", "logp", "rew", "val", "done"]}
    with torch.no_grad():
        for t in range(T):
            d = model.dist(obs)
            a = d.sample()
            buf["obs"].append(obs); buf["act"].append(a)
            buf["logp"].append(d.log_prob(a).sum(-1))
            buf["val"].append(model.v(obs).squeeze(-1))
            obs, r, done = env.step(a)
            buf["rew"].append(r); buf["done"].append(done)
        last_val = model.v(obs).squeeze(-1)
    b = {k: torch.stack(v) for k, v in buf.items()}            # [T, N, ...]
    adv, ret = gae(b["rew"], b["val"], b["done"], last_val)
    flat = lambda x: x.reshape(T * env.n, *x.shape[2:])
    ppo_update(model, opt, flat(b["obs"]), flat(b["act"]), flat(b["logp"]), flat(adv), flat(ret))
    if it % 25 == 0 or it == 149:
        print(f"iter {it:3d}  mean reward per step {b['rew'].mean():.3f}")

在我的运行中，每步平均奖励从约 $-0.89$（随机动作）上升到约 $-0.1$（质点到达原点并停住）。实践中很重要又很容易出错的细节：

  • 回合结束时的掩码。 mask 阻止在自动重置处继续自举。严格来说，时间限制造成的截断仍应从 $V(s_{T})$ 自举（机器人并没有 失败，只是我们不再观察了）；legged_gym 的做法是在超时时把最终状态的 $\gamma V$ 加到奖励上。玩具代码把超时当作终止，带来 少许偏差。
  • 优势归一化、梯度裁剪和与状态无关的 log-std 都是标准做法；观测归一化（滑动均值/方差）在真实机器人上很重要，因为 各物理量的单位可能相差几个数量级。
  • 动作缩放。 这里网络输出被截断到 $[-1, 1]$；在机器人上通常会缩放后加到名义关节构型上，$q^{\text{des}} = q_0 + k_a a_t$。

3. Soft Actor-Critic

PPO 每次更新后就丢弃数据。异策略（off-policy）方法保留一个经验回放缓冲区，样本效率高得多，这在样本来自真实机器人时 非常关键。SAC（Haarnoja 等 2018）优化最大熵目标

\[J(\pi) = \sum_t \mathbb{E}_{(s_t,a_t)\sim\pi}\left[r(s_t,a_t) + \alpha\,\mathcal{H}(\pi(\cdot\mid s_t))\right],\]

在完成任务的同时让策略尽可能随机。这带来稳健的探索，并且策略不会坍缩到某一个脆弱的解上。SAC 学习两个软 Q 函数 $Q_{\phi_1}, Q_{\phi_2}$（像 TD3 一样取最小值以对抗过估计），目标为

\[y = r + \gamma\left(\min_{j=1,2} Q_{\bar\phi_j}(s', \tilde a') - \alpha\log\pi_\theta(\tilde a'\mid s')\right), \qquad \tilde a' \sim \pi_\theta(\cdot\mid s'),\]

其中 $\bar\phi$ 是缓慢更新（Polyak 平均）的目标网络。演员使用 tanh 压缩高斯的重参数化技巧， $\tilde a = \tanh(\mu_\theta(s) + \sigma_\theta(s)\odot\xi)$，$\xi\sim\mathcal{N}(0, I)$，并最小化

\[L_\pi(\theta) = \mathbb{E}_{s\sim\mathcal{D},\,\xi}\left[\alpha\log\pi_\theta(\tilde a\mid s) - \min_j Q_{\phi_j}(s, \tilde a)\right].\]

tanh 改变了概率密度，因此 $\log\pi(\tilde a\mid s) = \log\mathcal{N}(u;\mu,\sigma) - \sum_i\log(1-\tanh^2 u_i)$。后续论文（Haarnoja 等 2018b） 还会把 $\alpha$ 自动调向目标熵（常取 $-\dim\mathcal{A}$），并展示了在真实的 Minitaur 四足机器人上直接学会行走，只用了约两小时的经验。

  PPO SAC
数据 同策略，更新后丢弃 异策略，回放缓冲区
样本效率 低 高

4. 奖励设计

奖励就是任务的规格说明，任何漏洞都会被找到。常见模式：

  • 稠密的任务项（例如速度跟踪用 \(\exp(-\lVert v^{\text{cmd}}_{xy} - v_{xy}\rVert^2 / \sigma)\)）加上许多小的正则化惩罚（力矩、功率、 关节加速度、动作变化率 $\lVert a_t - a_{t-1}\rVert^2$、足部打滑、腾空时间）。正是这些惩罚让步态看起来自然且可迁移；没有它们， 策略会高频抖动，仿真器能容忍，电机却受不了。
  • 基于势的奖励塑形（potential-based shaping，Ng、Harada 与 Russell，ICML 1999）：对任意势函数 $\Phi$ 加上 \(F = \gamma\Phi(s') - \Phi(s)\)， 可以证明不改变最优策略，而其他塑形项则可能改变它。
  • 稀疏奖励加示范或课程，用于操作任务：成功/失败容易定义，却难以探索，于是加入示范（第 4 篇）、自动课程（如 Rudin 等的 做法，随策略进步提高地形难度）或目标重标记。
  • 来自数据的风格奖励：动作模仿（DeepMimic，Peng 等 2018）或对抗运动先验会奖励策略”看起来像”参考动作捕捉数据， 这是从角色动画通往机器人的一座直接桥梁。
  • LLM 编写的奖励：Eureka（Ma 等 2024）让 LLM 编写奖励代码，在 Isaac Gym 中训练策略，再把训练统计反馈给 LLM 以改进奖励。

5. 仿真到现实迁移

在仿真中训练的策略要面对现实差距（reality gap）：错误的质量和摩擦、未建模的执行器动力学、延迟、传感器噪声，以及与渲染 图像毫不相像的真实图像。主要工具如下。

域随机化

与其让仿真器完全正确，不如让它以多种方式随机地出错，使真实世界看起来只不过是又一个样本。Tobin 等（IROS 2017）在一个 非照片级的渲染器中随机化纹理、光照、相机位姿和干扰物，训练出的物体检测器在没有任何真实图像的情况下，在真实机器人上的 定位误差平均约为 1.5 cm。Peng 等（ICRA 2018）随机化动力学（质量、摩擦、阻尼、延迟），并使用能隐式辨识当前动力学的 循环策略。OpenAI 的灵巧手工作（2018、2019）把它推向极致，提出自动域随机化，随策略成功而逐步扩大范围。

在代码中，随机化只是在重置时为每个环境重新采样物理参数。在上面的玩具任务中：

class RandomizedPointReach(PointReach):
    """Domain randomization: every env gets its own damping and actuator gain."""
    def reset(self):
        self.damp = torch.empty(self.n, 1).uniform_(0.8, 0.97)
        self.gain = torch.empty(self.n, 1).uniform_(0.05, 0.2)
        return super().reset()

把 PointReach(n=64) 换成 RandomizedPointReach(n=64)，同样的 PPO 循环就能学到一个对所有这些”机器人”都有效的单一策略。 （为简洁起见，参数在每次 reset() 时采样一次；完整实现会在每个环境自动重置时重新采样。）代价是保守性：范围越宽，策略越 稳健，但也越不最优。

系统辨识与执行器模型

随机化不能代替把大的方面做对。Hwangbo 等（Science Robotics 2019）训练了一个执行器网络（actuator network），这是一个 MLP， 把一小段关节位置误差和速度的历史映射为真实串联弹性执行器输出的力矩，训练数据采自 ANYmal。把它接入仿真器后，大部分 差距被弥合；学到的策略跑得比此前基于模型的控制器更快，还能在复杂姿态下从摔倒中恢复，这是手工设计的控制器没有做到的。

特权教师、学生与自适应

仿真器知道机器人永远无法知道的东西：精确的地形、摩擦、接触状态。利用这些知识有两类流行做法：

  • 非对称演员-评论家（asymmetric actor-critic，Pinto 等 RSS 2018）：评论家看到完整的仿真状态，而演员只看到机器人的观测。 部署时评论家会被丢弃，所以它”作弊”也无妨。
  • 教师-学生蒸馏（Lee 等 Science Robotics 2020）：先用特权信息训练教师策略，再训练一个只看本体感觉历史的学生去模仿教师。 学生学会通过腿部的”手感”推断地形。这让 ANYmal 能走过训练中从未见过的泥地、雪地、碎石和植被。Miki 等（2022）进一步 用基于注意力的方式融合外部感知（由相机和 LiDAR 得到的高度图）与本体感觉，机器人完成了瑞士 Etzel 山的一条徒步路线。
  • 快速运动自适应（Rapid Motor Adaptation，Kumar 等 RSS 2021）：把特权的环境参数编码为一个隐式”外在因素”向量，并训练 一个自适应模块，根据最近的状态和动作在线估计它。

大规模并行仿真

Rudin 等（CoRL 2021）表明，借助 Isaac Gym 在单块 GPU 上运行数千个环境，配合受游戏启发的地形课程和精心调参的 PPO， 可以在四分钟内训练出平地上的四足策略，在大约二十分钟内训练出崎岖地形上的策略，并且策略能迁移到真实的 ANYmal 上。 他们开源的 legged_gym 成了一代运动控制工作的模板，包括人形机器人（Radosavovic 等，Science Robotics 2024）。 启示是：当仿真很便宜时，简单的同策略算法胜出。

flowchart LR
  A[机器人模型 URDF/MJCF] --> B[GPU 仿真器, 4096 个环境]
  B --> C[带特权评论家的 PPO]
  R[域随机化: 质量, 摩擦, 延迟, 地形] --> B
  C --> D[教师策略]
  D --> E[学生策略: 本体感觉历史]
  E --> F[真实机器人, 200 Hz 以上的 PD 回路]

6. 运动控制之外

  • 操作。 用引导策略搜索训练的端到端视觉运动策略（Levine 等 JMLR 2016）；基于大规模真实数据的 QT-Opt 抓取；用 Shadow 手完成的手内重定向（OpenAI 2018）。对 RL 来说，操作比运动更难，因为奖励稀疏，相关状态（物体位姿、接触）难以感知，这也是 如今操作任务以模仿学习（第 4 篇）为主的原因。
  • 敏捷飞行。 冠军级无人机竞速（Kaufmann 等 Nature 2023）把仿真中的 RL 与数据驱动的感知和动力学残差模型结合起来。
  • 基础策略的 RL 微调。 RL 越来越多地被用来改进由模仿预训练的策略，使用成功奖励或学习得到的奖励模型；本文的思想可以 直接沿用。

动手试试

Lab 中的 XPBD 布料演示是一个带子步与约束投影的物理仿真器，正是 RL 智能体在其中训练的那类引擎。 拖动布料就是一个稳健策略必须抵抗的扰动；把随机化布料的刚度和质量想象成域随机化即可。

练习

  1. 从 $\nabla_\theta\log p_\theta(\tau)$ 推导策略梯度定理，并证明与状态相关的基线不会引入偏差。
  2. 在 PPO 代码中把 gae 的 lam 分别设为 0 和 1，比较学习曲线。再把 clip 设为 10（相当于不裁剪），观察稳定性。
  3. 修正时间限制带来的偏差：让 PointReach.step 分别返回 terminated 和 truncated 标志，并在截断时从最终观测的价值自举。
  4. 在 PointReach 上训练，然后在参数取极端值的 RandomizedPointReach 上评估，并与用随机化训练的策略比较。把真实阻尼加入 观测（”特权”输入），看看能帮多少。
  5. 为同一任务实现 SAC（回放缓冲区、双 Q、tanh 高斯、自动 $\alpha$），并比较它与 PPO 所需的环境步数。
